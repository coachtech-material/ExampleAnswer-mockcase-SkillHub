# マイルストーンマスタ（Certify LMS 開発参画）— 受講生配布版・草案【案①: チケット単位】

> COACHTECH LMS のタスク管理機能で、運営側が登録するマイルストーンマスタ。
> 各受講生にはこの内容（タイトル + サマリー）がコピーされ、受講生はマイルストーン配下に自分でタスクを起こして進捗を管理する。
>
> - **案①: チケット単位** — 1 チケット = 1 マイルストーン（全 41 件）+ チケット外の工程 2 件（参画準備 / 最終提出）の計 43 件。受講生はチケットごとに、作業工程（調査 / ヒアリング / 実装 / テスト・動作確認 / PR など）をタスクとして起こす
> - 「★」付きはフェーズ 2: Advance のチケット（フェーズ 1: Basic のチケットをひととおり完了してから着手）
> - 並び順はチケット一覧と同じ種別順: 参画準備（1）→ Basic: Story（2〜10）/ Bug（11〜26）/ Task（27〜28）→ Advance: Story（29〜33）/ Bug（34〜36）/ Task（37〜42）→ 仕上げ（43）。並び順は着手順を拘束しない（フェーズ内の着手順は自由。「タスク分解のヒント」末尾に前提チケットの記載がある場合のみ、そちらを先に完了させる）
> - 各チケットの要件詳細は要件シート（チケット一覧）を参照。マイルストーンの概要はチケットの要旨のみを示す

---

## 1. 参画準備・プロジェクト理解

■ 概要
自リポジトリの生成・環境構築から、既存プロジェクトの全体像把握までを行うマイルストーン。コードはまだ書かない。ここでのコードリーディングが以降すべてのチケットの土台になる。

■ タスク分解のヒント
自リポジトリの生成（Use this template）と環境構築、README の通読、ONBOARDING.md を手がかりにしたコードリーディング（プロジェクト構造・主要ドメインモデル・既存パターンの所在）、3 ロール（受講生・コーチ・管理者）でのログインと主要画面の巡回、テストの実行（環境構築直後は一部が失敗すること、それがバグ修正チケットに対応することの確認）、チケット一覧の通読と進め方の計画。
